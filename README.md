# 楽しい九九マスター 🌟

小学校低学年の子どもたちが楽しく九九を学習できるWebブラウザゲームです。

## ゲームの特徴

### 🎮 3つのモード
1. **「〇の段」練習モード**: 特定の段を集中的に練習
2. **ランダム出題モード**: 1の段から9の段までランダムに出題
3. **タイムアタックモード**: 決められた問題数を何秒でクリアできるか競う

### ✨ 派手なアニメーション
- 正解時に画面全体を使った派手なアニメーション
- 星が弾けるパーティクルエフェクト
- キャラクターが喜ぶアニメーション
- カラフルな背景変化

### 🎁 ご褒美システム
- 正解するたびに「九九星人」のカードがコレクションに追加
- ランダムでレア度が変わる（通常・レア・超レア）
- 称号システム（例：「7の段マスター」）

### 📊 達成度管理
- 各段の正答率を記録
- 全段制覇の進捗を表示
- ローカルストレージでデータを永続化

## 使い方

### 起動方法
1. `index.html`をWebブラウザで開く
2. メインメニューからモードを選択
3. ゲームを開始！

### 操作方法
- **問題**: 画面に表示された九九の問題を見る
- **回答**: 選択肢から正しい答えをクリック
- **タイマー**: 制限時間内にできるだけ多く正解しよう

## 技術スタック

- **HTML5**: セマンティックな構造
- **CSS3**: アニメーション、レスポンシブデザイン
- **JavaScript (Vanilla)**: ゲームロジック、ローカルストレージ
